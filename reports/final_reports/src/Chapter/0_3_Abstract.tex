\begin{center}
    \Large{\textbf{ABSTRACT}}\\
\end{center}
\vspace{0.8cm}

Long-term conversational agents need more than a large context window. They must preserve user facts across sessions, retrieve scattered evidence, and answer questions whose solution depends on time, preferences, causal links, or multi-hop reasoning. Plain vector retrieval and aggressively compressed summaries are often insufficient because they flatten different memory types and lose exact details needed at generation time.

This thesis presents \textbf{CogMem}, a cognitively grounded long-term memory architecture for conversational agents. CogMem organizes memory as a heterogeneous graph with six fact types -- \textit{world, experience, opinion, habit, intention, action\_effect} -- and seven edge families. It keeps lossless \textit{raw\_snippet} metadata beside compressed fact text, uses SUM-based spreading activation with cycle guards for graph recall, and routes queries adaptively across semantic, BM25, graph, and temporal channels.

The final evaluation uses manually verified answers rather than trusting automatic judge fields. On the LongMemEval v16 verified subset, the best multi-channel configuration reaches \textbf{29/35 PASS} (82.9\%), while the full six-type multi-channel baseline reaches \textbf{26/35 PASS} (74.3\%). On LoCoMo, the final evidence-guard configuration reaches \textbf{119/161 manual PASS} (73.9\%), improving over the previous baseline of 97/161 (60.2\%). The strongest LoCoMo slices are multi-hop (11/12), causal (10/11), and preference (15/17), while temporal questions remain the main limitation at 5/12.

These results suggest that CogMem is already a viable long-term memory system for difficult dialogue benchmarks, especially when evidence diversity and generation grounding are treated as first-class design goals. The remaining failures are concentrated in exact enumeration, temporal span calculation, and a small number of blank-gold hallucination cases.
