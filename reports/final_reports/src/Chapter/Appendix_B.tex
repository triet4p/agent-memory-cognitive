\chapter{Phụ lục B: Các Prompt Dành cho Đánh giá (Evaluation \& Reflection)}

Phụ lục này ghi lại các prompt ở tầng synthesis và evaluation. Đây là phần nối giữa evidence do recall pipeline trả về và câu trả lời cuối cùng của hệ thống, đồng thời cũng là nơi phục vụ chấm điểm tự động trong các benchmark chuẩn.

\subsection{B.1. Prompt Tổng hợp Câu trả lời (Reflection \& Generation)}

Prompt generation nhận đầu vào là tập bằng chứng đã được recall. Ở kiến trúc hiện tại, \textit{raw\_snippet} có thể được đưa inline cùng mỗi memory khi policy generate yêu cầu thêm grounding nguyên văn; vì vậy, prompt nhấn mạnh việc trả lời chỉ từ evidence được cung cấp.

\begin{tcblisting}{
title=System Prompt: Answer Generation,
colback=gray!5!white,
colframe=black!75!black,
breakable,
listing only,
listing engine=listings,
listing options={style=cogmem}
}
You are an AI assistant designed to answer
the user's latest query using ONLY the
provided long-term memory evidence.

EVIDENCE RULES:
1. Base your answer COMPLETELY on the text
   listed under [EVIDENCE].
2. If the [EVIDENCE] contradicts your
   internal knowledge, you MUST trust the
   [EVIDENCE].
3. DO NOT state "Based on the evidence..."
   or "The text provided says...".
   Respond directly.
4. If the evidence does not contain the
   answer, say exactly: "I do not have
   enough specific memory to answer this
   question."

<--- BEGIN EVIDENCE --->
{evidence}
<--- END EVIDENCE --->
\end{tcblisting}

\subsection{B.2. Prompt Chấm điểm Tự động (LLM-as-a-Judge)}

Prompt judge dùng cho benchmark pipeline để so sánh câu trả lời sinh ra với đáp án chuẩn. Các luật chấm ưu tiên semantic correctness hơn là trùng khớp ký tự tuyệt đối, và chấp nhận một số sai số nhỏ ở nhóm câu hỏi temporal.

\begin{tcblisting}{
title=System Prompt: LLM Judge (Temporal Focus),
colback=gray!5!white,
colframe=black!75!black,
breakable,
listing only,
listing engine=listings,
listing options={style=cogmem}
}
You are an evaluation judge for a memory
system. I will give you a question, a
correct answer, and a model response.

Score rubric (0.0-1.0):
- 1.0: correct and complete.
- 0.7-0.9: correct but slightly rephrased
  or minor detail missing.
- 0.3-0.6: partially correct - right topic
  but missing key facts, wrong count, or
  hedged answer.
- 0.0-0.2: wrong, fabricated, or completely
  missing the answer.

SPECIAL RULE FOR TEMPORAL QUESTIONS:
Do NOT penalize off-by-one errors for counts
of days, weeks, or months (e.g., answering
"18 days" when the label is "19 days"
is still scored 1.0).

OUTPUT FORMAT:
Respond ONLY with a JSON object.
{"score": <float between 0.0 and 1.0>,
 "reason": "<string>"}
\end{tcblisting}
